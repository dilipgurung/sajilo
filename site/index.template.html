Download for macOS

Free · macOS 14 or newer · All releases

Unsigned installer. A double-click is blocked, so right-click Sajilo.pkg → Open, then click Open again.

It learns what you pick. Choose a lower suggestion once and it moves up the list next time.

It spells words it has never seen. Names and new words get a rule-based reading, so dilip still becomes दिलिप.

Caps Lock types English. No switching input sources for a quick English word.
