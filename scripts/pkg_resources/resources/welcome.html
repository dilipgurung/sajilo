Sajilo

This installer copies Sajilo into your personal Input Methods folder so you can type Devanagari (नेपाली) by typing roman characters.

What this installer does:

  • Copies Sajilo.app to ~/Library/Input Methods/ (your account only — no admin password needed).
  • Asks macOS to refresh its list of input sources.

After install you'll need to enable the input source manually — see the next screen for the steps.
