Almost done — enable Nepali IME

macOS doesn't auto-enable input methods for security reasons. To finish setup:

  1. Open System Settings → Keyboard.
  2. Under Text Input, click Edit… next to Input Sources.
  3. Click the + button (bottom-left), search "Nepali", select Nepali IME, and click Add.
  4. Switch to it via the input-source menu in the menu bar (the small flag/globe icon), or press Control + Space.
  5. Open TextEdit and type namaste — you should see नमस्ते as a candidate. Press Space to commit.
Reinstalling? If the icon still shows the old version, remove the input source in System Settings and re-add it — macOS caches the icon aggressively.

The installer shipped a ~30,000-headword dictionary built from AI4Bharat's Aksharantar dataset and a hand-curated lemma seed.

To uninstall later: drag ~/Library/Input Methods/NepaliIME.app to the Trash. Optionally also remove ~/Library/Application Support/NepaliIME/ to clean up the learner database and user dictionary.

Logs: open Console.app and filter on com.gurungdilip.inputmethod.NepaliIME.
